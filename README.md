# fc

__NOTE: This is experimental software.__

fc is a web front-end to the [CES](https://github.com/fcecin/ces) network. Users can register a valid e-mail address and get a starting amount of credits which allows them to try out CES right away.

fc requires its own CES server to be installed in the same machine as part of its back-end.

`USING.md` contains installation, deployment, and development notes.
